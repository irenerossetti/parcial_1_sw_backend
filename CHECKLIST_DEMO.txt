│  30 MINUTOS ANTES DE LA DEMO                                  │
└───────────────────────────────────────────────────────────────┘

[ ] Iniciar backend
    cd backend
    ./start-backend.bat
    Esperar: "Started BackendApplication"

[ ] Iniciar frontend
    cd diagram
    npm start
    Esperar: "Compiled successfully"

[ ] Abrir frontend en navegador
    http://localhost:4200

[ ] Login como admin
    Email: admin@example.com
    Password: admin123

[ ] Probar chatbot
    Clic en botón flotante azul
    Escribir: "Hola"
    Verificar respuesta

[ ] Probar plantillas AI
    Ir a "Plantillas AI" en el menú
    Buscar: "instalación"
    Clic en "Buscar con AI"
    Verificar resultados

[ ] Probar asistente de voz
    Ir a "Políticas" → Crear/Editar
    Clic en "Diagrama"
    Clic en botón de micrófono
    Permitir acceso al micrófono
    Decir: "Agregar nodo validación"
    Verificar que se crea el nodo

[ ] Verificar que hay al menos 1 política creada

[ ] Verificar que hay al menos 1 departamento creado

Posibles preguntas y respuestas:

[ ] "¿Qué modelo de AI usan?"
    → GPT-3.5-turbo de OpenAI vía OpenRouter

[ ] "¿Por qué OpenRouter?"
    → Más económico que OpenAI directo, misma calidad

[ ] "¿Cómo funciona la búsqueda semántica?"
    → Usa embeddings de OpenAI para entender contexto

[ ] "¿El asistente de voz funciona en otros idiomas?"
    → Actualmente español, pero se puede extender

[ ] "¿La app móvil funciona offline?"
    → No, requiere conexión para sincronizar con backend

[ ] "¿Qué tecnologías usaron?"
    → Backend: Spring Boot + MongoDB
    → Frontend: Angular 21 + GoJS
    → Móvil: Flutter
    → AI: OpenRouter API
