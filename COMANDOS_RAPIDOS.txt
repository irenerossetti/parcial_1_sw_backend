===========================================
COMANDOS RÁPIDOS - COPIAR Y PEGAR
===========================================

=== 1. INICIAR BACKEND ===
cd backend
./start-backend.bat

=== 2. INICIAR FRONTEND ===
cd diagram
npm start

=== 3. CONFIGURAR FLUTTER ===
# Edita: flutter/lib/core/services/api_service.dart
# Línea 6, cambia a:

# Android Emulator:
static const String baseUrl = 'http://10.0.2.2:8080/api';

# Dispositivo físico (reemplaza X.X con tu IP):
static const String baseUrl = 'http://192.168.X.X:8080/api';

# iOS Simulator:
static const String baseUrl = 'http://localhost:8080/api';

=== 4. EJECUTAR FLUTTER ===
cd flutter
flutter pub get
flutter run
